pwd - показывает где находимся
cd + скопируй папку - перейди в эту папке.
git init - начать работу
git add - ввести
git status - проверить статус 
git commit - внести изменения
i - добавить комментарий что сделал
esc + дописать :x! закончить commit
get log - проверить действия
get log --graph - проверить все действия подряд красиво
